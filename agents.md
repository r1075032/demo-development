## Commit guidelines
Every commit must be a convetional commit. Please follow the conventional commit guidelines when making changes to this repository. This ensures that the commit history is clear and consistent, making it easier for others to understand the purpose of each change.

use the present tense when writing commit messages, and be concise yet descriptive. For example, use "fix" for bug fixes, "feat" for new features, and "docs" for documentation changes. Avoid using vague terms like "update" or "change" without specifying what was updated or changed.

## Security guidelines
When contributing to this repository, it is important to follow security best practices. Avoid committing sensitive information such as passwords, API keys, or personal data. If you accidentally commit sensitive information, please contact the repository maintainers immediately to address the issue.
